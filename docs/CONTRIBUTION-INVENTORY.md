# AX23 contribution inventory

Baseline reviewed: Sply upstream `main` at `a5d48b1cd94f0d09b73d0341c95ef76b286a9b21`. The engineering source is the separate `john35413/openwrt-archer-ax23-v2-build` project; its latest fetched `dev` was `916a6d3d8e493b6eefc6c14ff10aa1b1789553f1`. The seven patches selected below are exact copies of the standalone OpenWrt patch wrappers. They do not contain board data. The prepared OpenWrt source used for our separate build is based on Sply's documented OpenWrt base, but this contribution branch has not itself been rebuilt.

**Evidence boundary:** upstream reports RAM boot, 2.5 Gb/s switch trunk, LAN forwarding, WAN connectivity, MAC and LED results on its test hardware. Its Wi-Fi still reports board-file fetch `-12`. Our offline source/model tests do not establish physical Wi-Fi, RF, recovery or Ethernet behavior. The proposed ath11k/Q6 series addresses host memory and failure cleanup; it does **not** prove or claim to fix board-file lookup `-12`.

### Included in this draft

Patches 0006–0012 in this repository carry standalone patches 0002, 0012, 0018, 0019, 0022, 0026 and 0027. They are grouped as one constrained-memory and startup-failure series; the underlying OpenWrt patch files retain their original contents and attribution. No Ethernet DTS, switch reset GPIO, RF target-power table, board-data binary, calibration dump, firmware image, or persistent-install path is changed.

All seven contributions have been compiled in the separate standalone OpenWrt build described by that project's manifest; this does not establish a build of this upstream fork branch or physical validation. No upstream maintainer approval is implied.
